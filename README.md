# AMAN Protocol (بروتوكول أمان)

### Decentralized Smart Insurance Platform (DeIn) & Dynamic Risk Architecture
بنية تحتية سيادية معيارية للتأمين اللامركزي الذكي وإدارة المخاطر اللحظية، محمية بالكامل ضمن منظومة **Arabian Eagle Ecosystem (A.E.C.)** لتأمين الأصول المادية والتجارية لرواد شبكة Pi Network عالمياً.

## 🧭 المبادئ الحاكمة والنزاهة التقنية لعام 2026
1. **الامتثال وفصل الصلاحيات:** يلتزم البروتوكول بالكامل بحدود المعاملات المعزولة (Pi Network Sandbox Boundary) ولا يسمح بأي تداخل مباشر مع عتاد الأجهزة أو المودم لضمان الخصوصية التامة.
2. **الأقساط الديناميكية:** يتم تعديل الأقساط شهرياً بناءً على قراءات التيليميتري، الطقس، والبيانات الساتلية المستقاة من محركات الذكاء الاصطناعي المتعددة.
3. **التسوية الهجينة والمجمعات:** تُدفع الأقساط بعملة Pi لحظياً وفقاً لتسعير الـ AMM والـ DEX المقابل للدولار، بينما تُدفع تعويضات الأضرار للمستفيدين عبر رمز **YER** المشفر لضمان مرونة السيولة واستقرار البنية التحتية.

## 📁 الهيكل الهندسي للمستودع
* `contracts/`: يحتوي على العقود الذكية متعددة الأطراف لإصدار الوثائق وإقرار الحوادث.
* `ai-engine/`: يحتوي على محرك الذكاء الاصطناعي المتعدد والتعلم الذاتي.
* `server/`: الخادم الخلفي لتنفيذ المعاملات وحساب أسعار الصرف الفورية.
* `.github/workflows/`: ملفات التحقق الأمني المؤتمت لتفعيل الشارة الخضراء ✅.

## 🚀 شروط التشغيل والبناء (Replit Deployment)
يتم جلب وبناء هذا المستودع ديناميكياً فور ربطه بمنصة Replit، حيث تقوم إعدادات `replit.nix` و `.replit` بتشغيل البيئة المتقاطعة (Node.js + Python) بالتزامن دون تداخل.
